# Capstone catalogue

The ordered slug inventory in [`projects`](projects) lists the projects
available in this archive and is the packaging source of truth. For each slug,
start with `capstones/<slug>/README.md` to compare its product goal,
prerequisites, and verification contract.

The current choices, in catalogue order, are:

1. [`tabbyshell/`](tabbyshell/) — a typed, NuShell-inspired interactive shell.
2. [`snap/`](snap/) — a vector-clock version control system with deterministic
   automatic merging.

Each project includes its specification, language-neutral acceptance tests,
test harness, verifier, and a starting workspace in your selected language.
